# Contributing

Thanks for improving Regex Lab. Please keep changes focused and cross-platform.

1. Fork or branch from `main`.
2. Create a virtual environment and run `python -m pip install -e . pytest`.
3. Add or update tests for behavior changes.
4. Run `python -m pytest` before opening a pull request.
5. Keep public CLI behavior documented in README.md.

Bug reports should include the command, Python version, operating system, expected result, and actual result. Never include secrets or sensitive input data in reports.

## المساهمة

نرحب بالمساهمات المركزة والقابلة للاختبار. ثبّت المشروع و`pytest` محليًا، وأضف اختبارًا لأي تغيير سلوكي، وشغّل الاختبارات قبل فتح Pull Request. لا تضع أسرارًا أو بيانات حساسة في تقارير الأخطاء.
